# ADR 0003 — Same-origin English PWA

Status: accepted, 2026-11-05.

## Decision

Keep NestJS/Prisma/PostgreSQL as the system of record. Add a React/Vite PWA in the web workspace.
Nest serves the compiled client at / and OAuth return at /oauth; Swagger stays at /api/docs.
The Railway Docker image contains both builds, so no second hosting origin or CORS credential setup is needed.

Use provisioned usernames with existing HttpOnly sessions/CSRF. Password changes require the old password
and revoke every session for that member. Never persist credentials, CSRF tokens or financial responses in client storage.
Only the temporary public Plaid Link token is held in sessionStorage during OAuth and removed on completion/logout.

Workbox precaches app code, manifest-related icons and the public shell only. API/health/webhooks bypass SPA fallback.
Offline startup shows the shell and connection state; offline mutations and financial-history caching are out of scope.
Updates require an explicit Update & reopen action. Transaction drafts must be saved before updating.

## Product and design

English only, short task labels, no promotional or decorative prose.
Kami parchment/ink-blue palette, Charter/Georgia headings, system sans-serif tabular amounts.
Monthly income/spending/refunds and the review queue lead; review count spans all posted transactions.
Desktop sidebar becomes four bottom tabs on phone. Phone installation requires reachable HTTPS.

## Consequences

Frontend edits use the existing integer-cent JSON and optimistic version protocol.
Only changed fields are submitted, preserving archived categories on note/review updates.
Actual bank connection remains user-driven; real OAuth/iPhone/Railway verification is still required.
Updates means the in-app daily digest inbox. Web Push needs a separate subscription/delivery implementation.
Tests and screenshots are recorded in VERIFICATION.md; durable visual tokens live in DESIGN.md.
